# World Economic Map — Frontend

React 19 + TypeScript + Vite web app for the World Economic Map: an interactive,
zoomable heatmap world map of official economic, health and social data, plus
bilateral trade flow visualization.

## Development

```bash
npm install
npm run dev      # dev server → http://localhost:5173
npm run build    # production build → dist/
npm run lint     # ESLint
```

## Data

Static data lives in `public/data/*.json` (generated by the Python pipeline in
`../pipeline`). The app loads it via `src/data/useWorldData.ts` — no backend, no API keys.

## i18n

English is the default language; German is available via the switch in the
top-right corner. UI strings live in `src/i18n.ts`, metric labels are stored
bilingually in the data files (`label`/`labelDe` = German, `labelEn` = English).
