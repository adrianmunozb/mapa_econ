# CSV exports

Generated by `python -m wem export` from `app/public/data/snapshot.json` and
`timeseries.json` (no network needed). Values are exactly those shown in the app;
attribution and licence per indicator are in `indicators.csv`.

| File | Rows | Columns |
|---|---|---|
| `history/<indicator>.csv` | one per country with any value | `iso3`, `country`, then one column per year (empty cell = no value) |
| `latest.csv` | one per country | `iso3`, `country`, `region`, `income_group`, then the latest value of every indicator |
| `indicators.csv` | one per indicator | label (DE/EN), domain, unit, source, licence, indicator code, history coverage |

Notes: `policy_rate` has no annual history (latest value only). `inflation` in `latest.csv`
is the current monthly IMF rate, while `history/inflation.csv` is the annual World Bank series.
